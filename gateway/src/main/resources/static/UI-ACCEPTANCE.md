# 商城界面验收说明

## 设计与边界

页面为中文数码办公商城，使用本地资源和原生 HTML/CSS/JavaScript，无前端构建依赖。色板：深青 `#193942`、交互青蓝 `#087e8b`、浅薄荷 `#e7f2f1`、冷白 `#f3f8f9`、分隔线 `#dce7e9`、正文白 `#ffffff`。字体为系统已有的微软雅黑或苹方，不访问字体服务。

布局：顶部商品/购物车/订单导航，首页左文案右桌面插画，下方左对齐的分类和搜索、三列商品网格；移动端为两列网格和换行导航。其他页签保持相同框架。主要视觉来自数码设备 SVG，颜色用于区分实际操作和状态，不加动画或外部组件。

账户与客服使用原生 dialog，支持 Esc 关闭、焦点限制与键盘操作。交互元素有明显焦点，输入具有标签；主要反馈为文本状态。所有业务接口从同域 `/api` 调用，接口报错显示后端返回信息。支付按钮标记“模拟支付”，提示不会扣款；客服标记商品检索与常见问题问答。

登录令牌只保存到 sessionStorage。注册成功要求登录，不冒充注册已经建立会话。退出删除令牌、清空当前界面的账户购物车。购物车创建订单附带 UUID，失败重试沿用同一 requestId，成功后清除。

## 浏览器验收顺序（需实际后端运行）

1. 打开网关首页，确认 6 个商品 SVG 显示、商品分类和价格来自接口；搜索“键盘”，切换分类，确认结果匹配；清空搜索。
2. 点击“登录 / 注册”，选择注册，填写唯一用户名和密码，注册成功后登录；再次使用相同用户名注册应显示后端错误。
3. 使用错误密码登录，确认错误明确；正确登录后顶部显示用户名。刷新页面，应保持本标签页会话。
4. 加入两个商品。打开购物车，修改数量为 2，失焦后确认数量/金额更新；删除商品，确认消失。输入非法数量 0 或 1.5，显示整数范围提示并还原。
5. 点击“创建订单”，确认购物车清空、订单明细与金额正确、状态为“待支付”，页面明确说明模拟支付。
6. 点击“模拟支付”，确认显示“已支付”，已支付订单不出现取消按钮。再创建一笔待支付订单，点击“取消订单”，确认“已取消”。
7. 打开购物助手，点击“推荐键盘”，确认有真实答复；点击返回的商品，回到商品搜索结果。询问“如何支付？”和“取消订单”，确认可理解的流程回答。
8. 退出登录，购物车与订单显示登录引导，个人内容清空。未登录点击“加入购物车”打开登录窗口。
9. 将视窗缩至 390 × 844，确认无横向溢出、按钮可见，弹窗适配；用 Tab/Enter 操作主导航、分类、登录和客服，用 Esc 关闭弹窗。
